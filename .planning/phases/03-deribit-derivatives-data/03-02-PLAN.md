<objective>
Complete the Deribit data pipeline by normalizing raw API responses into analysis-ready Parquet tables, validating schemas against fixtures, and writing quality summaries. This plan builds on the client and discovery pipeline from Plan 01, adding the normalization layer that converts JSON-RPC responses into the same provenance-tracked Parquet format used by the Kalshi pipeline. All normalized tables follow the ProvenanceRow pattern (source_endpoint + source_raw_path in every row), use Polars TABLE_SCHEMAS for schema-preserving writes even on empty tables, and represent missing optional fields as null (per D-11, no imputation or forward-fill).

Purpose: Produce normalized, schema-stable Deribit tables that Phase 4 can consume for probability modeling and look-ahead guard enforcement.
Output: Working normalization pipeline with Parquet outputs, quality summaries, and end-to-end test coverage.
</objective>
