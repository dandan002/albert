<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User shell -> CLI | User-controlled command arguments and environment variables enter Typer and config loading. |
| Config TOML -> Pydantic model | User-controlled TOML values become filesystem roots for later cache and run writes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `src/albert/config.py` path fields | mitigate | Reject empty path strings, null bytes, and `..` path parts in `AlbertConfig`; cover with `tests/test_config.py::test_rejects_parent_traversal_paths`. |
| T-01-02 | Information Disclosure | `src/albert/config.py` config keys | mitigate | Reject config keys containing `secret`, `token`, `password`, `api_key`, or `apikey`; cover with `tests/test_config.py::test_rejects_secret_like_config_keys`. |
| T-01-03 | Repudiation | CLI command wiring | accept | Phase 1 command groups are placeholders with no external writes; provenance is mitigated in Plan 02 manifests. |
</threat_model>
