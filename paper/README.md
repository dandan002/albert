# Black–Scholes for Binaries (paper)

LaTeX sources for the paper on prediction-market price dynamics (information clocks, jumps,
smiles and hazard term structures on Kalshi). The research code is in `src/albert/research/`
(`pm_vol.py`, `pm_smile.py`, `pm_hazard.py`); the plain-text notes are
`.planning/research/PM-VOL-MODEL.md`.

- `main.tex` is the frame. `sections/*.tex` holds the sections, `macros.tex` the shared notation,
  `references.bib` and `bib/*.bib` the bibliography.
- `figures/*.pdf` are generated by `scripts/fig_*.py` from the study outputs under
  `data/research/` (not in git). `scripts/figstyle.py` is the shared figure style. Run them with a
  separate venv that has matplotlib, polars, numpy and scipy (`make figures`).
- Every table and key number has a `% source:` comment naming the output file it came from.

Build with `make` (TeX Live: pdflatex, bibtex, latexmk). `make arxiv` writes `arxiv.tar.gz`,
which includes `main.bbl` as arXiv requires.

The author block in `main.tex` is a placeholder.
